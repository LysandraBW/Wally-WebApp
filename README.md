## Wally
**PICTURES AND VIDEOS AT THE BOTTOM!**

This project began several years ago when I started to learn about programming on FreeCodeCamp. I was a bored teen with abundant time due to the COVID-19 pandemic. 

As helping my hard-working parents has been (and still is) the most important of my life, I set out to make a web application in which they could better manage their customers and schedule.

The first version was a chunk of HTML in CodePen -- I obviously had no idea what I was getting into. Thankfully, I was somehow able to continue improving with each iteration, which brings me to this GitHub repository.


### Functionality
This web application provides the following functionality:
* Customers:
  * Schedule appointments
  * View scheduled appointment

* Employees:
  * View scheduled appointments
  * Edit scheduled appointments
  * Create and share events to their calendar


### Run Front-End
To run the front-end side of this project, you'll need to start the server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```


### Run Back-End
To run the back-end side of this project, you'll need to head over to the "API" repository (https://github.com/LysandraBW/API) and start that server. In case I don't include a README.md there, you can use the same commands as above.


### Roadmap
Alas, there is no roadmap; it turned out that my beloved parents did not need an application as their customers tend to be older. I should've known to learn the audience I was serving. Alas.

However, I think these would still be good features to develop in the future if I ever return to this project.
* Customer:
  * Customer can delete their appointment
  * Customer can pay for their appointment
* Employee:
  * Employee can create an appointment (for a customer)
  * Boss can manage mechanics (e.g. assign them vehicles to fix)
  * Employees can order parts
  * Employees can bill the customer
  * Employees can upload pictures in their notes (used to be a feature, but I was scared of being thrown into destitution by AWS so I removed it)
